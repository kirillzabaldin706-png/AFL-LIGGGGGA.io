УСТАНОВКА ПРИЛОЖЕНИЯ АФЛ (PWA)
==============================

Сайт работает как приложение без публикации в App Store / Google Play.

Android (Chrome):
1. Откройте сайт в Chrome
2. Меню ⋮ → «Установить приложение» / «Добавить на главный экран»
   или нажмите кнопку «Установить приложение» на сайте

iPhone / iPad (только Safari):
1. Откройте сайт в Safari
2. Кнопка «Поделиться»
3. «На экран «Домой»» → «Добавить»

Компьютер (Chrome / Edge):
1. Откройте сайт
2. В адресной строке — иконка установки (⊕ / компьютер)
3. «Установить»

После установки АФЛ открывается в отдельном окне без адресной строки браузера.

Для публикации в App Store / Google Play нужна отдельная сборка
(Capacitor / React Native) и аккаунты разработчика — это платно и дольше.
