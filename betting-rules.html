Правила виртуальных ставок (звёзды)

Не азартные игры за деньги. Ставки только на внутреннюю валюту «звёзды». Вывод в рубли невозможен. См. также Правила звёзд.

Рынки

  • П1 / X / П2 — исход матча
  • ТБ 2.5 / ТМ 2.5 — тотал голов больше / меньше 2.5
  • ОЗ да / нет — обе забьют
  • Кто забьёт — игрок отмечен в протоколе голов (текстовое поле «Голы» в админке)

Расчёт

После статуса матча «Завершён» открытые ставки пользователя пересчитываются при входе на сайт. Выигрыш = ставка × коэффициент (округление вниз).

Споры

Решение администрации по внутренним ставкам окончательно в рамках сервиса. Ошибки протокола исправляются вручную.
