# Безопасность АФЛ

## Обязательно сделай в Firebase Console

1. Realtime Database → Rules → вставь содержимое файла `database.rules.json` → Publish
2. Authentication → только Email/Password (или что используешь)
3. Смени пароль админа на длинный (16+), не используй его на других сайтах
4. Включи 2FA на Google/GitHub аккаунтах

## Что закрыто правилами

- Команды, матчи, игроки, новости, реклама, турниры, состав, персонал, настройки, магазин — **только email админа**
- Предложения — писать могут все, читать только админ
- Звёзды пользователя — лимиты на значение; бонус регистрации ≤ 1000
- Ставки — сумма 10…100000, кэф 1.01…100; создать open только от своего uid

## Ограничения без Cloud Functions

Расчёт выигрышей идёт в браузере. Полностью исключить подкрутку звёзд может только сервер (Cloud Functions). Для любительской лиги текущих правил обычно достаточно, если пароль админа надёжный.

## ImgBB

Ключ в клиенте могут использовать чужие. При злоупотреблении смени ключ на api.imgbb.com.

## GitHub

Включи 2FA. Не давай посторонним push в репозиторий сайта.
